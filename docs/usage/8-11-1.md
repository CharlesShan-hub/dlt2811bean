# 8.11.1 选择服务 (Select)

## 概述

1. 选择控制对象，为后续 Operate 做准备。Select 只锁定控制对象，不携带控制参数。
2. 同一控制对象一次只能被一个 session 选择，其他 session 操作会返回 `INSTANCE_LOCKED_BY_OTHER_CLIENT`。
3. 选择后需要通过 Operate 执行控制，或通过 Cancel 取消选择。
4. 对应 CLI 命令：`select`

## 使用场景

### 1. 选择控制对象（select → operate 两段式）

```bash
cms> connect --ap C_B5041X/S1
cms> select --ref LD0/CTRL1.SPC1
  Selecting: LD0/CTRL1.SPC1
  OK  Selected LD0/CTRL1.SPC1
cms> operate --ref LD0/CTRL1.SPC1 --value true --origin 1 --ctlNum 5 --test false
  Operating: LD0/CTRL1.SPC1
  OK  Operated LD0/CTRL1.SPC1
```

### 2. 选择后取消

```bash
cms> select --ref LD0/CTRL1.SPC1
  OK  Selected LD0/CTRL1.SPC1
cms> cancel --ref LD0/CTRL1.SPC1
  OK  Canceled: LD0/CTRL1.SPC1
```

### 3. 选择被其他 session 占用

```bash
cms> select --ref LD0/CTRL1.SPC1
  ERR Select rejected: INSTANCE_LOCKED_BY_OTHER_CLIENT (8)
```
