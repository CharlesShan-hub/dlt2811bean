# §8.6.5 GetEditSGValue — 读编辑定值组值服务

## 概述

1. 读取编辑定值组内数据属性的值。
2. 也可通过指定 `--fc SG` 获取当前激活组的值。
3. 对应 CLI 命令：`get-edit-sg`

## 协议原文

### 8.6.5 读编辑定值组值服务(GetEditSGValue)

#### 8.6.5.1 服务参数

读编辑定值组值服务用于读取编辑定值组内数据属性的值，服务的参数见表 44。

**表 44 读编辑定值组值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| sgcbReference | | ObjectReference |
| value [1..n] | | |
| reference | value | ObjectReference |
| fc | value | FunctionalConstraint |
| **Response+** | | |
| value [1..n] | | Data |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> get-edit-sg --refs "PROT/OCPTOC2.StrVal"
  Fetching edit SG values (SG) for 1 ref(s)
  Edit SG values (1 items):
    [0] PROT/OCPTOC2.StrVal  [visible-string] (unavailable)
# Confirm 后可以读到值
cms> confirm-edit-sg --ref "PROT/DeZonePTOC1.SG1"
cms> get-edit-sg --refs "PROT/OCPTOC2.StrVal"
  Edit SG values (1 items):
    [0] PROT/OCPTOC2.StrVal  [int32] 100
```
