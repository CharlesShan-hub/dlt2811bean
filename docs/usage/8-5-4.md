# §8.5.4 DeleteDataSet — 删除数据集服务

## 概述

1. 删除之前动态创建的数据集。
2. 只能删除通过 CreateDataSet 创建的数据集，静态数据集不可删除。
3. 对应 CLI 命令：`delete-dataset`

## 协议原文

##### 8.5.4.1 服务参数

删除数据集服务用于删除动态创建的数据集，服务的参数见表 38。

**表 38 删除数据集服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| dataSetReference | | ObjectReference |
| **Response+** | | |
| result | | ServiceError |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> delete-dataset --ds "LD0/LLN0.myDs"
  Deleting dataset LD0/LLN0.myDs
  OK  Deleted dataset LD0/LLN0.myDs successfully
cms> get-dataset-dir --ds "LD0/LLN0.myDs"
  ERR GetDataSetDirectory rejected: INSTANCE_NOT_AVAILABLE (1)
```
