# §8.6.2 SelectEditSG — 选择编辑定值组服务

## 概述

1. 选择一个定值组作为**编辑组**，后续的 SetEditSGValue 操作将修改该组的定值。
2. 对应 CLI 命令：`select-edit-sg`

## 协议原文

### 8.6.2 选择编辑定值组服务(SelectEditSG)

#### 8.6.2.1 服务参数

选择编辑定值组服务用于选择一个定值组为当前编辑定值组，服务的参数见表 41。

**表 41 选择编辑定值组服务参数**

| 服务/参数 | 数据类型 |
|-----------|----------|
| **Request** | |
| sgcbReference | ObjectReference |
| groupNumber | INT8U |
| **Response+** | |
| result | ServiceError |
| **Response-** | |
| serviceError | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> sgcb-vals --refs "LD0/LLN0.SG1"
  SGCB values (1 items):
    [0] LD0/LLN0.SG1  numOfSG=4 actSG=1 editSG=1
cms> select-edit-sg --ref "LD0/LLN0.SG1" --num 2
  Selecting edit SG: ref=LD0/LLN0.SG1 num=2
  OK  Edit SG set to 2 for LD0/LLN0.SG1
cms> sgcb-vals --refs "LD0/LLN0.SG1"
  SGCB values (1 items):
    [0] LD0/LLN0.SG1  numOfSG=4 actSG=1 editSG=2
```
