# 8.9.1 发送GOOSE消息服务 (SendGOOSEMessage)

## 概述

1. SendGOOSEMessage 用于服务器向其他设备**发送 GOOSE 消息**，属于**服务器主动推送**的报文（Indication）。
2. 客户端不发送此服务，由服务器在数据变化或周期到达时自动发送。
3. GOOSE 消息包含 goID、stNum（状态序号）、sqNum（序列号）、confRev（配置版本号）和 data（数据值数组）等。
4. 该服务**无确认报文**，服务器发送即结束。
