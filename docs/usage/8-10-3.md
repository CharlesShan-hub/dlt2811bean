# 8.10.3 设置多播采样值控制块值服务 (SetMSVCBValues)

## 概述

1. 设置多播采样值控制块（MSVCB）的属性值，如 svEna、msvID、datSet 等。
2. 启用采样值发送（svEna=true）后，服务器按 smpRate 配置的频率自动发送采样值。
3. 对应 CLI 命令：`set-msvcb-vals`
