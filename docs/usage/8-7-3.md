# §8.7.3 SetBRCBValues — 设置缓存报告控制块值服务

## 概述

1. 修改缓存报告控制块（BRCB）的属性，如 rptID、datSet、bufTm、intgPd、rptEna、gi 等。
2. 先设其他属性最后设 rptEna 为 true 以启用报告。
3. 对应 CLI 命令：`set-brcb-vals`

## 协议原文

##### 8.7.3.1 服务参数

设置缓存报告控制块值服务用于修改缓存报告控制块内的一个或多个属性，服务的参数见表 48。

**表 48 设置缓存报告控制块值服务参数**

| 服务/参数 | 数据类型 |
|-----------|----------|
| **Request** | |
| brcbReference | ObjectReference |
| rptID[0..1] | VisibleString129 |
| rptEna[0..1] | BOOLEAN |
| datSet[0..1] | ObjectReference |
| confRev[0..1] | INT32U |
| optFlds[0..1] | RcbOptFlds |
| bufTm[0..1] | INT32U |
| intgPd[0..1] | INT32U |
| gi[0..1] | BOOLEAN |
| purgeBuf[0..1] | BOOLEAN |
| resvTms[0..1] | INT16 |
| **Response+** | |
| result | ServiceError |
| **Response-** | |
| serviceError | ServiceError |

##### 8.7.3.2 服务要求

设置 BRCB 值时，符合以下要求。

a) rptEna 由 false 改为 true 时，服务器应先设置 rptEna 之前的所有属性，再设置 rptEna，最后设置 rptEna 之后的属性。

b) rptEna 由 true 改为 false 时，服务器应在设置 rptEna 属性后忽略 rptEna 属性之后的属性值。

## 使用场景

```bash
cms> connect --ap P_B5041A/S1
cms> set-brcb-vals --ref LD0/LLN0.brcbDeviceState --dat-set "dsDeviceState" --buf-tm 2000
  Setting BRCB values: ref=LD0/LLN0.brcbDeviceState
  OK  BRCB values set for LD0/LLN0.brcbDeviceState
cms> get-brcb-vals --refs "LD0/LLN0.brcbDeviceState"
  BRCB values (1 items):
    [0] LD0/LLN0.brcbDeviceState  rptID=LD0/LLN0$BR$brcbDeviceState rptEna=false datSet=dsDeviceState confRev=1 bufTm=2000 sqNum=0 intgPd=0
cms> set-brcb-vals --ref LD0/LLN0.brcbDeviceState --purge-buf true
  OK  BRCB values set for LD0/LLN0.brcbDeviceState
cms> set-brcb-vals --ref LD0/LLN0.brcbDeviceState --intg-pd 60000 --rpt-ena true
  OK  BRCB values set for LD0/LLN0.brcbDeviceState
```
