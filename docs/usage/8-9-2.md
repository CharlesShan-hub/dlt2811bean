# 8.9.2 读GOOSE引用服务 (GetGoReference)

## 概述

1. 获取 GOOSE 控制块数据集的成员引用（含 fc）。
2. 通过 `gocbReference` 指定 GoCB 引用，通过 `memberOffset` 指定要查询的成员序号。
3. 对应 CLI 命令：`get-go-ref`

## 协议原文

#### 8.9.2 读GOOSE引用服务(GetGoReference)

读GOOSE引用服务的参数见表58。

**表58 读GOOSE引用服务参数**

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> get-go-ref --ref CTRL/LLN0.gocb0 --offsets "1 2 3"
  Fetching GOOSE reference: ref=CTRL/LLN0.gocb0 offsets=1,2,3
  OK  Got GOOSE reference
```
