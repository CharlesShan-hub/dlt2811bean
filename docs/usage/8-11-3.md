# 8.11.3 执行服务 (Operate)

## 概述

1. 执行控制操作。控制对象必须先通过 Select 或 SelectWithValue 选择。
2. 执行后自动释放选择锁。
3. 对应 CLI 命令：`operate`

## 协议原文

#### 8.11.3 执行服务(Operate)

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> select --ref LD0/CTRL1.SPC1 --value true
cms> operate --ref LD0/CTRL1.SPC1 --value true --origin 1 --ctlNum 5 --test true
  OK  Operated: LD0/CTRL1.SPC1
```
