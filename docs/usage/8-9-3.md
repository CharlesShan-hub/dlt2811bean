# 8.9.3 读GOOSE元素序号服务 (GetGOOSEElementNumber)

## 概述

1. 根据数据集成员的引用和 fc，反查成员在数据集中的**序号（offset）**。
2. 与 GetGoReference 互为逆操作。
3. 对应 CLI 命令：`get-goose-elem`

## 协议原文

#### 8.9.3 读GOOSE元素序号服务(GetGOOSEElementNumber)

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> get-goose-elem --ref CTRL/LLN0.gocb0 --members "CTRL/GGIO1.Ind1,ST"
  Fetching GOOSE element number: ref=CTRL/LLN0.gocb0
  OK  Got GOOSE element numbers
```
