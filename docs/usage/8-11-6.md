# 8.11.6 时间激活操作服务 (TimeActivatedOperate)

## 概述

1. TimeActivatedOperate 用于客户端**预约在未来某个时间点**执行控制操作。
2. 通过 `operTm` 参数指定执行时间（UTC 时间戳，秒级）。
3. 服务器在指定时间到达时执行操作，可通过 CommandTermination 通知结果。
4. 对应 CLI 命令：`time-act-ope`
5. 当前实现为模拟，返回成功但不做实际定时调度。

## 使用场景

### 1. 定时执行

```bash
cms> connect --ap C_B5041X/S1
cms> time-act-ope --ref LD0/CTRL1.SPC1 --oper-tm 2000000000 --value true --origin 1
  TimeActivatedOperate: LD0/CTRL1.SPC1 at 2000000000
  OK  TimeActivatedOperate scheduled for LD0/CTRL1.SPC1
```
