# 8.11.2 带值选择服务 (SelectWithValue)

## 概述

1. 选择控制对象的同时附带控制值，相当于 Select + Operate 两步合一。
2. 同一控制对象一次只能被一个 session 选择。
3. 通过统一命令 `select` 调用，带 `--value` 参数时自动走 SelectWithValue。纯 `--ref` 时走 Select。

##### 8.11.2.2 服务要求

因为不同控制对象的数据类型不同，所以ctlVal的类型由模型定义。客户可通过解析模型文件获取ctlVal的类型，也可通过8.4.4的GetDataDefinition服务获取ctlVal的类型。以下控制类服务中的ctlVal与此相同。

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> select --ref LD0/CTRL1.SPC1 --value true --origin 1 --ctlNum 5
  Selecting with value: LD0/CTRL1.SPC1
  OK  Selected with value LD0/CTRL1.SPC1
```
