# §8.4.3 GetDataDirectory — 读数据目录服务

## 概述

1. 获取指定数据对象的所有子数据对象和数据属性的引用名。
2. LN 级列出 DO（不含 fc），DO 级列出 DA（含 fc）。
3. 支持 `--after` 分页。
4. 对应 CLI 命令：`data-dir`

## 协议原文

##### 8.4.3.1 服务参数

读数据目录服务用于获取指定数据对象的所有子数据对象和数据属性的引用名，服务的参数见表 33。

**表 33 读数据目录服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| reference | | ObjectReference |
| referenceAfter [0..1] | | ObjectReference |
| **Response+** | | |
| reference [0..n] | | SubReference |
| fc [0..n] | | FunctionalConstraint |
| moreFollows [0..1] | | BOOLEAN |
| **Response-** | | |
| serviceError | | ServiceError |

##### 8.4.3.2 服务要求

读数据目录服务的要求如下。

a) 读数据目录服务的子数据对象应不包含 fc，数据属性应包含 fc。

b) reference 为 LN 时，返回该 LN 下所有 DO（不含 fc）。

c) reference 为 DO 时，返回该 DO 下所有 DA（含 fc）。

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
  Connecting to 127.0.0.1:8102 ...
  Connected, negotiating parameters ...
  Negotiated, associating with C_B5041X/S1 ...
  OK  Associated: C_B5041X/S1
cms> data-dir --ref LD0/LLN0
  Data directory (16 items):
    [0] Mod
    [1] NamPlt
    [2] LEDRs
    ...

cms> data-dir --ref LD0/LLN0.Mod
  Data directory (5 items):
    [0] [CF]  ctlModel
    [1] [DC]  dU
    [2] [ST]  stVal
    [3] [ST]  q
    [4] [ST]  t

# 分页
cms> data-dir --ref LD0/LLN0 --after Health
  Data directory (1 items):
    [0] Loc
```
