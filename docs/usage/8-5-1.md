# §8.5.1 GetDataSetValues — 读数据集值服务

## 概述

1. 获取数据集所有成员的值。
2. 支持 `--after` 分页。
3. 对应 CLI 命令：`get-dataset-values`

## 协议原文

##### 8.5.1.1 服务参数

读数据集值服务用于获取数据集所有成员的值，服务的参数见表 35。

**表 35 读数据集值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| dataSetReference | | ObjectReference |
| referenceAfter [0..1] | | ObjectReference |
| **Response+** | | |
| value [0..n] | | Data |
| moreFollows [0..1] | | BOOLEAN |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> get-dataset-values --ds "LD0/LLN0.dsAlarm"
  Fetching dataset values for LD0/LLN0.dsAlarm
  No dataset values returned
# 设置值后
cms> set-dataset-values --ds "LD0/LLN0.dsAlarm" --values "true false true"
cms> get-dataset-values --ds "LD0/LLN0.dsAlarm"
  DataSet values (3 items):
    [0] [boolean] true
    [1] [boolean] false
    [2] [boolean] true
# 分页
cms> get-dataset-values --ds "LD0/LLN0.dsAlarm" --after "LD0/GGIO1.Alm1"
  No dataset values returned （无更多数据）
```
