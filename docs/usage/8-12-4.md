# §8.12.4 GetFileAttributeValues — 读文件属性值服务

## 概述

1. 获取文件的属性信息，如文件名、大小、修改时间、校验和。
2. 对应 CLI 命令：`get-file-attrs`

## 协议原文

#### 8.12.4 读文件属性值服务(GetFileAttributeValues)

读文件属性值服务的参数见表75。

**表75 读文件属性值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| fileName | | VisibleString255 |
| **Response+** | | |
| fileEntry | | FileEntry |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> set-file --local D:/test.txt --remote /test.txt
  Uploading D:/test.txt -> /test.txt ...
  OK  Uploaded D:/test.txt to /test.txt successfully
cms> get-file-attrs --file /test.txt
  Fetching file attributes for /test.txt
    fileName=/test.txt
    fileSize=9
    lastModified=1783412991932
    checkSum=871209221
```
