# 8.11.4 取消服务 (Cancel)

## 概述

1. 取消一个待执行的控制操作。
2. 通常用于取消 Select 或 SelectWithValue 的锁定。
3. 对应 CLI 命令：`cancel`

## 协议原文

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> select --ref LD0/CTRL1.SPC1 --value true
cms> cancel --ref LD0/CTRL1.SPC1
  OK  Canceled: LD0/CTRL1.SPC1
```
