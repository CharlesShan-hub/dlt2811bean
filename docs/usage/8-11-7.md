# 8.11.7 时间激活操作终止服务 (TimeActivatedOperateTermination)

## 概述

1. TimeActivatedOperateTermination 用于服务器通知客户端**定时操作已执行完毕**（由服务器发起，客户端接收）。
2. 该服务**无确认报文**，服务器单方面发送后即结束。
3. 无对应的客户端 CLI 命令，由服务器自动推送。
4. 当前服务端有 skeleton 实现。
