# §8.6.3 SetEditSGValue — 设置编辑定值组值服务

## 概述

1. 设置编辑定值组内数据属性的值。必须先 SelectEditSG 再执行本服务。
2. 支持多种数据类型：int32（默认）、float32、boolean、visible-string 等。
3. 对应 CLI 命令：`set-edit-sg`

## 协议原文

### 8.6.3 设置编辑定值组值服务(SetEditSGValue)

#### 8.6.3.1 服务参数

设置编辑定值组值服务用于设置编辑定值组内数据属性的值，服务的参数见表 42。

**表 42 设置编辑定值组值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| sgcbReference | | ObjectReference |
| value [1..n] | | |
| reference | value | ObjectReference |
| value | value | Data |
| **Response+** | | |
| result | | ServiceError |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap P_B5041A/S1
cms> select-edit-sg --ref "PROT/DeZonePTOC1.SG1" --num 1
  OK  Edit SG set to 1 for PROT/DeZonePTOC1.SG1
cms> set-edit-sg --refs "PROT/OCPTOC2.StrVal" --values "100" --type int32
  Setting edit SG values (int32) for 1 ref(s)
  OK  Edit SG values set successfully
```
