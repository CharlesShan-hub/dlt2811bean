# §8.5.5 GetDataSetDirectory — 读数据集目录服务

## 概述

1. 获取数据集的所有成员引用（含 fc）。
2. 支持 `--after` 分页。
3. 对应 CLI 命令：`get-dataset-dir`

## 协议原文

##### 8.5.5.1 服务参数

读数据集目录服务用于获取数据集所有成员的引用，服务的参数见表 39。

**表 39 读数据集目录服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| dataSetReference | | ObjectReference |
| referenceAfter [0..1] | | ObjectReference |
| **Response+** | | |
| member [0..n] | | |
| reference | member | ObjectReference |
| fc | member | FunctionalConstraint |
| moreFollows [0..1] | | BOOLEAN |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> get-dataset-dir --ds "LD0/LLN0.dsAlarm"
  DataSet directory (3 items):
    [0] [ST]  LD0/GGIO1.Alm2
    [1] [ST]  LD0/GGIO1.Alm1
    [2] [ST]  LD0/GGIO1.Alm3
cms> get-dataset-dir --ds "LD0/LLN0.dsAlarm" --after "LD0/GGIO1.Alm1"
  DataSet directory (1 items):
    [0] [ST]  LD0/GGIO1.Alm3
```
