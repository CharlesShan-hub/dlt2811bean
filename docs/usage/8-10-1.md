# 8.10.1 发送多播采样值消息服务 (SendMSVMessage)

## 概述

1. SendMSVMessage 用于服务器向订阅者**发送多播采样值消息**，属于服务器主动推送的报文（Indication）。
2. 客户端不发送此服务，由服务器在采样周期到达时自动发送。
3. 消息包含采样值数据（sample 数组）、采样计数器（smpCnt）、同步状态（smpSynch）、采样率（smpRate）等。
4. 该服务**无确认报文**，服务器发送即结束。
