# 8.10.2 读多播采样值控制块值服务 (GetMSVCBValues)

## 概述

1. 读取多播采样值控制块（MSVCB）的属性值，如 svEna、msvID、datSet、confRev、smpRate 等。
2. 支持一次请求多个 MSVCB 引用。
3. 对应 CLI 命令：`get-msvcb-vals`
