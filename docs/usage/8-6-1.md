# §8.6.1 SelectActiveSG — 选择激活定值组服务

## 概述

1. 选择一个定值组作为当前**激活组**，激活组的定值立即生效。
2. 对应 CLI 命令：`select-active-sg`

## 协议原文

### 8.6.1 选择激活定值组服务(SelectActiveSG)

#### 8.6.1.1 服务参数

选择激活定值组服务用于选择一个定值组为当前激活定值组，一旦选择激活后当前激活定值组内的定值立即生效，服务的参数见表 40。

**表 40 选择激活定值组服务参数**

| 服务/参数 | 数据类型 |
|-----------|----------|
| **Request** | |
| sgcbReference | ObjectReference |
| groupNumber | INT8U |
| **Response+** | |
| result | ServiceError |
| **Response-** | |
| serviceError | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
cms> sgcb-vals --refs "LD0/LLN0.SG1"
  SGCB values (1 items):
    [0] LD0/LLN0.SG1  numOfSG=4 actSG=1 editSG=1
cms> select-active-sg --ref "LD0/LLN0.SG1" --num 2
  Selecting active SG: ref=LD0/LLN0.SG1 num=2
  OK  Active SG set to 2 for LD0/LLN0.SG1
cms> sgcb-vals --refs "LD0/LLN0.SG1"
  SGCB values (1 items):
    [0] LD0/LLN0.SG1  numOfSG=4 actSG=2 editSG=1
```
