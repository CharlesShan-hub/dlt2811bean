# 8.9.5 设置GOOSE控制块值服务 (SetGoCBValues)

## 概述

1. 设置 GOOSE 控制块（GoCB）的属性值，如 goEna、goID、datSet 等。
2. 启用 GOOSE（goEna=true）后，服务器在数据变化或周期到达时自动发送 GOOSE 消息。
3. 对应 CLI 命令：`set-gocb-vals`

## 协议原文

#### 8.9.5 设置GOOSE控制块值服务(SetGoCBValues)

设置GOOSE控制块值服务的参数见表61。

**表61 设置GOOSE控制块值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| gocb[1..n] | | |
| reference | gocb | ObjectReference |
| goEna[0..1] | gocb | BOOLEAN |
| goID[0..1] | gocb | VisibleString129 |
| datSet[0..1] | gocb | ObjectReference |
| **Response+** | | |
| **Response-** | | |
| result[1..n] | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> set-gocb-vals --ref CTRL/LLN0.gocb0 --go-id "MyCustomGoID" --dat-set "dsGOOSE"
  Setting GoCB values: ref=CTRL/LLN0.gocb0
  OK  GoCB values set for CTRL/LLN0.gocb0
cms> set-gocb-vals --ref CTRL/LLN0.gocb0 --go-ena true
  OK  GoCB values set for CTRL/LLN0.gocb0
```
