# §8.8.2 读日志控制块值服务(GetLCBValues) — 读日志控制块值服务

## 概述

1. 获取日志控制块（LCB）的所有属性。
2. 对应 CLI 命令：`get-lcb-vals`

## 协议原文

```
#### 8.8.2 读日志控制块值服务(GetLCBValues)

读日志控制块值服务用于获取日志控制块的所有属性，服务的参数见表52。

**表52 读日志控制块值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| lcbReference[1..n] | | ObjectReference |
| **Response+** | | |
| error/lcb[1..n] | | ServiceError/LCB |
| moreFollows[0..1] | | BOOLEAN |
| **Response-** | | |
| result | | ServiceError |
```

## 使用场景

```bash
cms> connect --ap P_B5041A/S1
cms> get-lcb-vals --refs "LD0/LLN0.lcblog"
  Fetching LCB values for 1 reference(s)
    [LD0/LLN0.lcblog] logEna=true datSet=dsLog intgPd=0 logRef=LD0 trgOps=dc:false,qc:false,du:false,integrity:false,gi:false
```
