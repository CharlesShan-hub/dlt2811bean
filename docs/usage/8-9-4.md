# 8.9.4 读GOOSE控制块值服务 (GetGoCBValues)

## 概述

1. 读取 GOOSE 控制块（GoCB）的属性值，如 goEna、goID、datSet、confRev、ndsCom 等。
2. 支持一次请求多个 GoCB 引用。
3. 对应 CLI 命令：`get-gocb-vals`

## 协议原文

#### 8.9.4 读GOOSE控制块值服务(GetGoCBValues)

读GOOSE控制块值服务的参数见表60。

**表60 读GOOSE控制块值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| gocbReference[1..n] | | ObjectReference |
| **Response+** | | |
| error/gocb[1..n] | | ServiceError/GoCB |
| moreFollows[0..1] | | BOOLEAN |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1
cms> get-gocb-vals --refs "CTRL/LLN0.gocb0"
  Fetching GoCB values for 1 reference(s)
    [CTRL/LLN0.gocb0] goEna=false goID=C_B5041XCTRL/LLN0.gocb0 datSet=dsGOOSE confRev=1 ndsCom=false
```
