# 8.11.5 命令终止服务 (CommandTermination)

## 概述

1. CommandTermination 用于服务器通知客户端**命令执行完成**（由服务器发起，客户端接收）。
2. 是客户请求 Operate 后，服务器返回命令执行的最终结果（成功或失败）。
3. 该服务**无确认报文**，服务器单方面发送后即结束。
4. 在两种控制方式中的流程：**select → operate（正常完成）** 或 **select-with-value（带值选择完成）**。
