# §8.8.6 读日志状态值服务(GetLogStatusValues) — 读日志状态值服务

## 概述

1. 获取日志的状态信息，包括最早和最晚日志条目的时间和 ID。
2. 对应 CLI 命令：`get-log-status`

## 协议原文

```
#### 8.8.6 读日志状态值服务(GetLogStatusValues)

读日志状态值服务的参数见表56。

**表56 读日志状态值服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| logReference[1..n] | | ObjectReference |
| **Response+** | | |
| log[1..n] | | |
| error/value | log | ServiceError/log |
| oldEntrTm | log | EntryTime |
| newEntrTm | log | EntryTime |
| oldEntr | log | EntryID |
| newEntr | log | EntryID |
| moreFollows[0..1] | | BOOLEAN |
| **Response-** | | |
| serviceError | | ServiceError |
```

## 使用场景

```bash
cms> connect --ap P_B5041A/S1
cms> get-log-status --refs "LD0/LLN0.lcblog"
  Fetching log status for 1 reference(s)
    [LD0/LLN0.lcblog] oldEntrTm=60000/19782 newEntrTm=600000/19782
```
