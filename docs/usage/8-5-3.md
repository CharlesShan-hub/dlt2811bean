# §8.5.3 CreateDataSet — 创建数据集服务

## 概述

1. 动态创建新的数据集，或向已有数据集追加成员。
2. 通过 `--after` 区分创建新数据集和追加成员的场景。
3. 对应 CLI 命令：`create-dataset`

## 协议原文

##### 8.5.3.1 服务参数

创建数据集服务用于动态创建新的数据集，服务的参数见表 37。

**表 37 创建数据集服务参数**

| 服务/参数 | 所属 | 数据类型 |
|-----------|------|----------|
| **Request** | | |
| dataSetReference | | ObjectReference |
| member [1..n] | | |
| reference | member | ObjectReference |
| fc | member | FunctionalConstraint |
| referenceAfter [0..1] | | ObjectReference |
| **Response+** | | |
| result | | ServiceError |
| **Response-** | | |
| serviceError | | ServiceError |

## 使用场景

```bash
cms> connect --ap C_B5041X/S1;
# 创建新数据集
cms> create-dataset --ds "LD0/LLN0.myDs" --members "LD0/GGIO1.Alm1,ST LD0/GGIO1.Alm2,ST"
  Creating dataset LD0/LLN0.myDs with 2 member(s)
  OK  Created dataset LD0/LLN0.myDs successfully
# 追加成员
cms> create-dataset --ds "LD0/LLN0.myDs" --members "LD0/GGIO1.Alm3,ST" --after "LD0/GGIO1.Alm2"
  OK
```
